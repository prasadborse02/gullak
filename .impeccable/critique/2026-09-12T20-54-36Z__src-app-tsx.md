## Design Specificity Verdict

Authored where it matters: deposit chain (coin arc, pot bump, synthesized clink on landing chosen from pot state, toast), receipt card, dark theme with constant clay/brass. Still generic: mini-goal list is a card-per-row task list with three permanent icon buttons; dashboard opens with the tagline h1; wallet history is a bank statement.

Deterministic scan: CLI 2 warnings (Fraunces, bump easing, both deliberate). In-page: ₹ badge 4.36:1; "Next deposit" block is a nested card; one 90ch caption in the form; icon buttons 40x40.
